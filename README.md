# Smart-Agriculture-Prediction-System
A Flask-based Machine Learning web application that provides **crop and fertilizer recommendations** using agricultural and environmental parameters. The project integrates trained machine-learning models with a user-friendly web interface to support data-driven agricultural decision-making.

## 🚀 Features

- 🌾 Crop recommendation using Machine Learning
- 🧪 Fertilizer recommendation/prediction
- 🤖 Integration of trained ML models
- 🌐 Flask-based web application
- 📊 Agricultural data preprocessing and prediction
- 📱 User-friendly interface
- 📲 Twilio integration for notification/communication functionality

⚙️ Installation
1. Clone the Repository
git clone https://github.com/KUMARARYAN/AgricultureSite.git
cd AgricultureSite

2. Create a Virtual Environment
python -m venv venv

Activate it on Windows:
venv\Scripts\activate

3. Install Dependencies
pip install -r requirements.txt

4. Run the Application
python app.py

Open the application in your browser:
http://127.0.0.1:5000/

🎯 Objective
The objective of this project is to demonstrate how Machine Learning and Web Development can be combined to create a practical smart agriculture solution. The system processes agricultural parameters and provides prediction-based recommendations through a Flask web interface.
